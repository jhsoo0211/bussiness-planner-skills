## P1. 본편 코드 생성 (Claude Code / Codex)

```text
너는 모션그래픽 디렉터이자 프런트엔드 애니메이션 엔지니어다.
아래 기획대로 60초짜리 16:9 소개 모션그래픽을 단일 HTML 파일로 만들어라.

[목적]
한국 정부지원사업 사업계획서(PSST) 작성 스킬 "bizplan"이
① 작성 과정의 어느 지점에서 돕는지 가시화하고
② Claude Code와 Codex에 설치하는 방법을 보여준다.

[기술 규격]
- 단일 파일 motion.html. 무대 1920×1080 고정, 브라우저 창에 맞춰 비율 유지 축소.
- 애니메이션: GSAP 3.12.5 (https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js), 하나의 master timeline.
- 글꼴: Pretendard (https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css), 대체 Noto Sans KR.
- 녹화용: window.__seek(seconds) 를 노출해 timeline을 해당 시점으로 정확히 이동시킬 것. 자동재생은 ?autoplay=1 일 때만.
- 별도 파일 record.js: Playwright로 0~60초를 30fps로 __seek → 스크린샷(PNG 시퀀스) 저장, 이어서 ffmpeg로 motion.mp4(H.264, yuv420p) 합치는 명령을 주석으로 제공.

[디자인 토큰]
네이비 #1F3A5F(기본) / 오렌지 #F28C28(강조: 신규 기능·핵심 수치에만) / 배경 #F7F8FA / 그레이 #8A94A6 / 연네이비 #DCE4EE
플랫·미니멀 벡터, 넓은 여백, 인물 사진·악수·달러 기호·마스코트 금지, 기관 로고 금지.
모션은 ease-out 위주, 컷당 동작 1~2개, 전환 0.4~0.6초. "흩어진 것이 제자리에 맞물리는" 쾌감이 핵심.
화면 하단에 내레이션 자막 바를 상시 표시(흰 배경 위 네이비 텍스트, 32px 이상).

[씬 타임라인]
S1 0:00–0:05 빈 A4 문서 일러스트, 커서 깜빡임. 텍스트 "사업계획서, 어디서부터?"
S2 0:05–0:11 카드 4장(공고문 / 배점표 / 한글 양식 .hwp / PSST)이 위에서 떨어져 어지럽게 쌓였다가 한 줄로 정렬.
S3 0:11–0:15 정렬된 카드가 접혀 로고 "bizplan"으로 변환. 부제 "한국 PSST 사업계획서 스킬 15종".
S4 0:15–0:35 가로 여정 라인에 노드 6개가 차례로 점등(노드당 약 3초). 노드 위에 스킬명 칩, 아래에 미니 화면:
  1 아이디어 구체화 [bizplan-item][bizplan-quick] — 질문 카드 5장(업종·타겟·핵심기능·차별점·약점)이 기획 요약 1장으로 합쳐짐
  2 큰틀 잡기 [NEW 오렌지 배지] — "제목 → 중제목 → 소제목 → 한두 줄 요약" 트리가 위에서 아래로 펼쳐짐
  3 PSST 작성 [problem][research][solution][growth][team] — P·S·S·T 4블록, 문제 3개와 솔루션 3개 사이에 1:1 연결선이 그려짐
  4 시각자료 [bizplan-visual] — TAM·SAM·SOM 동심원이 바깥부터 차오르고, 포지셔닝맵에 점이 찍힘
  5 심사위원 검토 [bizplan-review][bizplan-analyze] — 100점 채점표에 O·△·X가 찍히고 "필수 수정 2건" 태그
  6 발표 준비 [bizplan-pitch][bizplan-slides] — 16:9 슬라이드 썸네일과 예상 질문 카드가 넘겨짐
  끝에 작은 칩 "수출바우처 전용 모드 [bizplan-export]"를 0.8초 노출.
S5 0:35–0:45 오렌지 NEW 배지 카드 3장이 차례로 뒤집힘:
  "큰틀 한눈에 보기" / "한글(HWPX) 파일로 받기" / "수상작·우수 사례 레퍼런스"
S6 0:45–0:56 좌우 분할 터미널 2개(어두운 네이비 배경, 고정폭 글꼴). 한 글자씩 타이핑 후 초록 체크.
  왼쪽 제목 "Claude Code"
    /plugin marketplace add jhsoo0211/bussiness-planner-skills
    /plugin install bizplan@business-planner-skills
  오른쪽 제목 "Codex"
    git clone https://github.com/jhsoo0211/bussiness-planner-skills.git
    cd bussiness-planner-skills
    python scripts/install_skills.py --agent codex
  마지막 줄만 크게 강조. 철자 주의: 저장소는 bussiness(s 두 번), 마켓플레이스는 business(s 한 번) — 그대로 둘 것.
S7 0:56–1:00 로고 + "막막함은 줄이고, 설득력은 높이고." + github.com/jhsoo0211/bussiness-planner-skills

[자막(내레이션) — 각 씬 시작에 맞춰 교체]
S1 빈 화면 앞에서 막막하셨나요?
S2 공고문, 배점표, 한글 양식, 그리고 PSST까지.
S3 bizplan이 순서대로 정리합니다.
S4 아이디어를 구체화하고, 큰틀을 잡고, 문제·해결·성장·팀을 차례로 씁니다. / 시장 도식을 그리고, 심사위원의 눈으로 채점한 뒤, 발표까지 준비합니다.
S5 이제 목차와 한두 줄 요약으로 전체 뼈대를 먼저 보고, 완성본은 한글 파일로 받습니다. / 수상작과 우수 사례로 기준도 높입니다.
S6 설치는 간단합니다. Claude Code는 명령어 두 줄, Codex는 저장소를 받아 설치 스크립트 한 번이면 됩니다.
S7 막막함은 줄이고, 설득력은 높이고. bizplan.

[검수 — 완료 전에 스스로 확인]
1. Playwright로 0, 3, 8, 13, 20, 27, 33, 40, 50, 58초 스크린샷을 찍어 확인: 텍스트 잘림·겹침 없음, 모든 한글이 정상 표시.
2. 화면의 명령어 문자열이 위 원문과 한 글자도 다르지 않을 것.
3. 오렌지는 NEW 배지·핵심 강조에만 쓰였을 것.
4. 결과 보고: 파일 경로, 녹화 방법, 검수 스크린샷 경로.
```

## P3. 공통 스타일 (AI 영상·이미지 생성기용, 모든 C 프롬프트 앞에 붙임)

```text
Flat minimal vector motion graphics, clean Korean corporate tone.
Palette strictly: navy #1F3A5F as the base, a single orange #F28C28 accent, off-white #F7F8FA background, light navy #DCE4EE and gray #8A94A6 as supporting tones.
Generous white space, soft ease-out motion, subtle depth with flat shadows only.
NO text, NO letters, NO numbers, NO logos anywhere in the frame — all typography will be composited later.
No photorealistic people, no handshake imagery, no dollar signs, no cartoon mascots, no neon, no glitch effects.
16:9, 1920x1080, 24–30 fps, seamless and calm.
```

## P4. 씬별 배경 컷 (텍스트 없음, 후합성 전제)

> 각 프롬프트 앞에 P3를 붙인다. 생성 후 한글 자막·카드 텍스트는 편집 툴이나 P1 HTML 위에 얹는다.

**S1 — 빈 문서와 커서 (5초)**
```text
A single blank A4 document page floating at the center of an off-white space, slightly tilted, gently breathing in scale.
A thin navy text cursor blinks on the empty first line. Camera slowly pushes in. Quiet, slightly tense mood.
```

**S2 — 쏟아지는 서류 카드 → 정렬 (6초)**
```text
Several blank rounded document cards (no text) fall from the top and pile up chaotically, overlapping and wobbling.
Halfway through, they lift, rotate and snap into one neat horizontal row with satisfying precision.
Navy cards, one card highlighted with an orange edge. Motion goes from messy to orderly.
```

**S3 — 카드가 접혀 하나의 형태로 (4초)**
```text
A neat row of navy cards folds together like an accordion into a single compact rounded square emblem at the center,
followed by a soft radial pulse of light navy. Clean and confident. Leave empty space below the emblem for a title.
```

**S4 — 여정 라인 배경 루프 (20초, 루프 가능)**
```text
A thin horizontal navy line runs across the frame with six evenly spaced circular nodes.
Each node lights up in sequence from left to right with a soft orange glow, then settles back to navy.
Faint light-navy grid in the background drifts slowly. Seamless loop. Leave clear space above and below each node for UI overlays.
```

**S5 — 카드 3장 뒤집기 (10초)**
```text
Three blank vertical cards stand in a row. One by one they flip 180 degrees to reveal an orange-accented face, with a gentle bounce.
Subtle particle sparkle around each flipped card, very restrained.
```

**S6 — 분할 화면 배경 (11초)**
```text
The frame splits vertically into two dark navy panels like two terminal windows with rounded corners and soft shadow,
on an off-white background. Very subtle scanline-free glow inside the panels. Static camera. Panels must stay empty for overlaid text.
```

**S7 — 마무리 (4초)**
```text
The rounded square emblem returns to the center, light navy rings expand outward once and fade.
Calm resolution, lots of empty space for a slogan and a URL below.
```
