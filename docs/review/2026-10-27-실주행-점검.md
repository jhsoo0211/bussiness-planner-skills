# bizplan 스킬 실주행 점검 (main `182e45a` 기준, 2026-10-27)

> 목적: ① 앞서 나온 검토 리포트(2026-10)의 기능 개선이 반영됐는지 ② PPT 템플릿·사업계획서 자료를 넣을 구조가 준비됐는지 ③ 실제 아이디어로 처음부터 끝까지 돌렸을 때 어디서 막히는지 확인한다.
> 실주행 입력: 사용자 팀의 실운영 핀테크 웹 서비스(비공개 저장소). **이 저장소가 공개 저장소이므로 실주행 산출물(사업계획서 초안·검토·슬라이드)은 커밋하지 않았다.** 아래에는 일반화한 결과만 적는다.

## 요약

1. **기능 개선은 반영되지 않았다.** 검토 리포트의 F1~F5·K1~K5·신규 기능 3종은 "상의 항목"으로 남아 있고 main에 구현된 것이 없다. 별도 기능 브랜치(`feat/author-insights-routing`)의 수정도 main에 병합되지 않았다.
2. **자료를 넣을 구조는 아직 준비되지 않았다.** 그대로 pptx·pdf를 커밋하면 파일이 깨졌다(실험으로 확인, 직전 커밋 `fix: pptx·pdf·hwp…`에서 수정). 템플릿을 둘 자리·읽는 절차는 어느 스킬에도 없다. 공개 저장소라 원문 자료의 저작권·개인정보 경계도 정해야 한다.
3. **실주행은 끝까지 돌았지만 사용자 요구 하나를 처리하지 못했다.** 라우터 → 빠른 초안 → 검토(가정 배점 49/100) → 발표 구성안(11장) → HTML 슬라이드(11장, 720px 검증 통과)까지 지침대로 진행됐다. 메모에 없는 수치·실적은 지어내지 않았다. 그러나 사용자가 처음부터 요구한 **학교 PPT 템플릿은 스킬 경로로 만들 수 없었다**(스킬 밖 python-pptx로만 가능). 지침끼리 충돌한 곳도 5곳 나왔다.
