## 판정 방법

각 기준을 **충족 / 부분 / 미충족 / 해당 없음**으로 기록하고 출력의 실제 인용 또는 위치를 붙인다. 중대한 근거 없는 확정은 별도로 기록한다. 인상 점수나 임의 가중 총점은 만들지 않는다. 간결한 초안도 기준을 의미상 충족하면 인정한다. 빠진 내용을 평가자가 추정하여 채우지 않는다.

작성자 노하우의 초기 적용 여부는 최종 초안의 실제 내용으로 판정한다. ‘참조 파일을 읽었다’는 실행 로그만으로 내용 적용을 인정하지 않는다. 반대로 이 문서만으로 파일 읽기 성공 여부를 추론하지 않는다. 명시 경로와 quick은 입력이 서로 다르므로 두 경로의 성능을 직접 비교하지 않는다. old/new의 동일 사례끼리만 내용 변화를 기술한다.

- 조건당 사례별 1회라면 탐색적 비교이며 반복성·일반화·전체 15개 스킬 우위를 입증하지 않는다.
- old/new 조건이 평가자에게 보이면 비맹검이라고 명시한다. 기준을 먼저 고정했다는 사실이 맹검을 의미하지 않는다.
- Case 1의 두 트랙, Case 2의 복수 파트, Case 3의 PSST는 각각 한 실행 안의 출력이다. 서로 독립 표본으로 세지 않는다.
- 순수 quick 경로와 복수 스킬 명시 경로는 과업도 다르므로 경로 간 점수 경쟁을 하지 않는다.
- 내용 평가, 지정 스킬 실제 로드, 실행시간·토큰 사용, DOCX/PDF 렌더·제출 형식 검증은 다른 증거다. 이 문서로 뒤의 세 가지를 판정하지 않는다.
- 가상 공고만으로 실제 U300/예창패 규정 준수나 실제 심사 통과를 주장할 수 없다. 시장 계산은 제공 가상 출처 범위 안에서만 확인한다.
