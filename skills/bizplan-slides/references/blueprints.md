사용자가 준 발표 템플릿 PDF 3종을 분석해 정리했다. 원본 파일은 공개 저장소에 넣지 않는다(`assets/templates/local/`에 보관). 분석은 색이 아니라 두 가지를 봤다.

- **어떤 정보를 어떤 순서로 놓는가**
- **어떤 형식으로 전달하는가**

장마다 붙은 관계 유형 코드(R1~R23)와 패턴(`type`)은 `bizplan-visual/references/info-patterns.md`, `scripts/theme_deck.py`와 같다.

## 1. 세 템플릿에 공통된 형식 문법

1. **머리 3단** — 위치 표시(브레드크럼 "02. 시장 환경 분석" 또는 작은 영문 머리말 "Budget Planning") → 결론형 제목 → 한 줄 설명("무엇을 보여주는 장인지"). 스펙의 `eyebrow` / `title` / `lead`에 해당한다.
2. **장 하나 = 관계 하나** — 본문 형식은 장마다 하나다. 한 장에 둘을 섞은 곳(B14)은 상세 부록 성격이다.
3. **바닥 결론 띠** — 병렬·비교·분석 장은 맨 아래 한 문장 결론으로 닫는다(A4·A13·A29, B5). 스펙에서는 `callout`이다.
4. **수렴 연결선** — 카드 3개 아래 점·선·화살표를 그려 결론 띠로 모은다(A4). 스펙에서는 `cards` + `converge`다.
5. **숫자는 크게, 단위는 작게** — '+50%', '약 0000원', '8+ · 2K · 15K · 200+'(A16, B4). `kpi`·`tam`이 자동으로 이렇게 쓴다.
6. **대단원 간지** — 5개 안팎의 대단원을 간지로 끊는다(번호 + 제목 + 한 줄 + 하위 항목). 스펙에서는 `section`이다.
7. **같은 정보를 해상도별로 반복** — 일정을 단계(A20·A21) → 분기 카드(A22) → 월 타임라인(A23) → 간트(A24)로 점점 자세히 보여준다. 발표 본문에는 하나만 쓰고 나머지는 부록으로 돌린다.
8. **끝은 요약 → 결론 → Q&A** — 요약 메시지 3행 → 화살표 → 한 문장 결론 띠 → 감사·Q&A(A29·A30).
9. **자사 강조는 색 하나로** — 비교 장에서 자사 머리·막대·원만 강조색이고, 경쟁 쪽은 회색이다(A10·A11·A12).
10. **표는 머리 띠 + 소계·합계 줄** — 예산 표는 구분 열을 병합하고 합계 줄을 옅은 회색으로 둔다(A18, B16).

- 정부지원사업 발표는 매출·투자·고용 세 숫자를 담은 장을 꼭 둔다(`bizplan-pitch` '지원사업 발표의 축'). 숫자는 사업계획서 숫자 등록부와 같아야 한다. 덱을 만든 뒤 `deck_check.py 슬라이드/발표.pptx --against 브리프.md`로 대조한다.
- 짧은 발표(3분 안팎)는 4블록 요약 구성(아이템 · 매출 · 투자 · 고용)으로 4~6장을 만든다.

## 6. 새 템플릿을 받으면

1. `scripts/theme_from_pdf.py 템플릿.pdf --out 슬라이드/테마분석/`으로 쪽 이미지·모아보기·색 후보를 뽑는다.
2. 장마다 위 표 형식으로 "전달하는 정보 / 형식 / 관계 / 패턴"을 적어 이 문서에 청사진을 하나 더 만든다. 원본이 비공개면 `assets/templates/local/<이름>.md`에 적는다.
3. 색·글꼴·머리 형식만 다르면 `assets/themes/<이름>.json`을 만든다. 기존 테마를 복사해 `colors`·`fonts`·`styles`를 바꾸고, 비공개면 `assets/themes/local/`에 둔다.
4. 패턴에 없는 형식이 반복되면 그 형식을 `theme_deck.py` 패턴 후보로 메모한다. 그때까지는 그림(`image`)이나 가까운 패턴으로 대신한다.
